📖 The 4 Chapters

The narrative lifecycle of turning JSON blueprints into living DOM.

Open Interactive Explorer →
CHAPTER 1
Identity

"Who are you?" Resolves the blueprint from the catalog by templateKey and validates its existence.

  • • Curated blueprint catalog
  • • Key existence verification
  • • Declarative HOW blueprint
CHAPTER 2
The Gatekeeper

"Are you worthy to enter?" Validates data payload against required contract keys/arrays and guards blueprint schema.

  • • Required key & array guards
  • • Void tag (<input>, <img>) guard
  • • Pre-compilation rejection
CHAPTER 3
Transformation

Compiles the guarded blueprint and dynamic data into pure Spec JSON via json-to-spec v3.

  • • HOW (structure) + WHAT (data)
  • • Iterations & string interpolations
  • • Pure Spec JSON output
CHAPTER 4
Realization

Breathes life into Spec JSON by constructing living interactive DOM elements via json-to-dom v27.

  • • Pure DOM materialization
  • • Event & action attachments
  • • Mounts directly to targetHtmlId
