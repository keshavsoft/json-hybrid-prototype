CHAPTER 1

Identity

"Who are you?"

The identity phase verifies that the requested component template exists within the registered blueprint catalog. It resolves the declarative HOW blueprint before any computation occurs.

Core Responsibilities:
  • Catalog Resolution: Looks up the template blueprint using templateKey.
  • Existence Verification: Immediately throws if the template is unregistered.
  • Blueprint Supply: Retrieves the declarative structure.json blueprint.
// Identity Check
const blueprint = getStructure({ templateKey: "customerForm" });
