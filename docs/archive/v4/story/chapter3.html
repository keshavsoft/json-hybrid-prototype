CHAPTER 3

Transformation

Structure (HOW) + Data (WHAT) → Pure Spec JSON

The Transformation phase takes the guarded blueprint (HOW) and merges it with the dynamic runtime data (WHAT). Powered by json-to-spec v3, it compiles into a pure, platform-independent Spec JSON tree.

Transformation Steps:
  • Loop Iterations: Expands arrays and collections according to blueprint repeat rules.
  • String Interpolations: Interpolates data values into text and attributes.
  • Pure Spec Output: Yields portable JSON representation ready for rendering.
