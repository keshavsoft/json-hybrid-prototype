🚀 Entry Point API Reference

Clean caller interface consuming the hybrid runtime with zero in- prefixes.

Primary Caller Method: renderTemplate()

Accepts 3 clean parameters to orchestrate the entire 4-chapter lifecycle and mount into DOM:

View Compiled Module 
import { renderTemplate } from "https://keshavsoft.github.io/json-hybrid-prototype/hybrid-runtime.js";

// 1. Prepare data matching the template blueprint contract
const data = {
  header: { title: "Customer Directory" },
  customers: [
    { name: "Asha Sharma", role: "Principal Architect" },
    { name: "Karthik Verma", role: "Frontend Lead" }
  ]
};

// 2. Orchestrates Chapters 1-4 and mounts directly into <div id="app"></div>
renderTemplate({
  templateKey: "customerForm",
  dataAsJson: data,
  targetHtmlId: "app"
});
Parameter Type Description
templateKey string Blueprint identifier registered in the template catalog (e.g. "customerForm", "salesTable").
dataAsJson object Dynamic data object satisfying the contract keys and arrays expected by the blueprint.
targetHtmlId string ID attribute of the DOM element where the materialized component will be mounted.
Additional Utility Methods
1. compileTemplate

Executes Chapters 1 through 3 to produce pure Spec JSON without mounting to DOM.

compileTemplate({ templateKey, dataAsJson })
2. getStructure

Retrieves the guarded structure blueprint for a given key (Chapters 1 & 2).

getStructure({ templateKey })
3. listTemplates

Discovers registered blueprints and metadata in the catalog.

listTemplates()
