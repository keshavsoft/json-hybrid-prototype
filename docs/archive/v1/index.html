v4 Story-Driven Architecture

The Story of a Data-Driven UI

A declarative UI pipeline connecting guarded structure.json blueprints (HOW) with dynamic data (WHAT), compiling via json-to-spec, and materializing into living DOM via json-to-dom.

THE 4-CHAPTER JOURNEY
Ch. 1 Identity: "Who are you?"
Ch. 2 The Gatekeeper: "Are you worthy?"
Ch. 3 Transformation: Structure + Data -> Spec
Ch. 4 Realization: Spec -> Living DOM

📖 The 4 Chapters

The narrative lifecycle of turning JSON blueprints into living DOM.

Interactive Explorer →
CHAPTER 1
Identity

"Who are you?" Resolves the blueprint from the catalog by templateKey and validates its existence.

  • • Curated blueprint catalog
  • • Key existence verification
  • • Declarative HOW blueprint
CHAPTER 2
The Gatekeeper

"Are you worthy to enter?" Validates data payload against required contract keys/arrays and guards blueprint schema.

  • • Required key & array guards
  • • Void tag (, ) guard
  • • Pre-compilation rejection
CHAPTER 3
Transformation

Compiles the guarded blueprint and dynamic data into pure Spec JSON via json-to-spec v3.

  • • HOW (structure) + WHAT (data)
  • • Iterations & string interpolations
  • • Pure Spec JSON output
CHAPTER 4
Realization

Breathes life into Spec JSON by constructing living interactive DOM elements via json-to-dom v27.

  • • Pure DOM materialization
  • • Event & action attachments
  • • Mounts directly to targetHtmlId
Clean Caller API

The Outside Entry Point

Strictly 3 self-documenting parameters with zero in- prefixes:

View CDN Module 
import { renderTemplate } from "https://keshavsoft.github.io/json-hybrid-prototype/hybrid-runtime.js";

// Sample Data matching the blueprint contract
const data = {
  header: { title: "Customer Directory" },
  customers: [
    { name: "Asha Sharma", role: "Principal Architect" },
    { name: "Karthik Verma", role: "Frontend Lead" }
  ]
};

// Orchestrates all 4 chapters and mounts directly into 

renderTemplate({
  templateKey: "customerForm",
  dataAsJson: data,
  targetHtmlId: "app"
});
1. Compile to Spec JSON

Execute Chapters 1 to 3 to produce Spec JSON without mounting:

compileTemplate({ templateKey, dataAsJson })
2. Supply Blueprint

Supply pure guarded structure blueprint (Chapters 1 & 2):

getStructure({ templateKey })
3. Discover Catalog

Discover registered blueprints and metadata:

listTemplates()
